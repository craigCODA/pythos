Method

About

PythOS is built as a verification-driven operating-system project. Claims are tied to source history, ADRs, serial markers, QEMU acceptance scripts, host-image checks, and physical artifacts.

Direction

The project explores an object-native computing model where typed objects, capabilities, revisions, graph packages, and object locators matter more than treating files and directories as the fundamental user abstraction.

Implementation

Implementation is agent-assisted under human architectural direction. The trusted record is the repository and evidence trail, not chat summaries.

Boundaries

AI remains outside the trusted core. PythCore owns privileged mechanisms; ordinary policy and future AI-facing workflows belong outside that boundary.

Current Stop

Phase 12 slice 1 is recorded; object-locator resolution, package management, networking, updates, hardware expansion, SMP, and later PythTIG phases remain gated.
